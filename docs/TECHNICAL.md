# 기술 설명

일본판 GFZJ01(『F-ZERO GX』, GameCube)을 해석한 내용입니다. 경로는 디스크의 `files/` 기준입니다.

## 디스크 구성

| 파일 | 내용 | 처리 |
| --- | --- | --- |
| `enemy_line/line__.bin` | 공용 실행 모듈 fz.main(REL). 메뉴·머신·파츠·도움말 등 문자열, 글자표 | `linebin.py`, `build.py` |
| `fz.*.rel` (title, sel, story, customize, option, profile, interview, movie, pilotpoint) | 화면별 실행 모듈 문자열 | `build.py` |
| `font/fnt_asc_24x24.bin` | 게임 글꼴(24×24, 1,387자) | `font.py` |
| `dlg/*_int.bin` | 우승 인터뷰 질문·답변 | `dlg.py`, `extra.py` |
| `movie/story*.txt` | 스토리 컷신 자막 | `extra.py` |
| `game/ja.gmo`, `game/game_msg_jp.txt` | 레이스 중 일시정지·확인 창 메시지 | `gmo.py` |
| `bmp/*.tpl.lz` | UI 텍스처(그림 글자) | `tpl.py`, `texpatch.py` |

## fz.main 모듈

- `line__.bin`은 32비트 빅엔디언 단위로 XOR 암호화되어 있습니다. 키는 LCG(시드 `0xDEADDEAD`, `x = x × 0xB5FB6483 + 0x4F107`)로 만들며, 갱신한 뒤 XOR합니다.
- 복호화한 결과는 아래의 AV LZ로 압축된 REL입니다.

## AV LZ 압축 (.lz)

- 8바이트 헤더: 압축 데이터 크기(헤더 8바이트 **제외**, 리틀엔디언 u32) + 원래 크기(리틀엔디언 u32).
- 본문은 Okumura LZSS입니다. 4KB 창, 시작 위치 0xFEE, 플래그 비트 1 = 리터럴, 0 = (12비트 위치, 4비트 길이+3) 참조.
- 헤더의 압축 크기에 헤더를 더해 적으면 게임이 멈춥니다. 다시 압축할 때는 최적 파싱(`avlz.compress_opt`)으로 원본보다 작게 만들고, 원본보다 커지면 빌드를 중단합니다.

## 글꼴과 문자 코드

- 게임 텍스트는 Shift-JIS입니다. 글꼴 파일의 글자 순서는 fz.main의 `0x1844C0`에 있는 Shift-JIS 글자표(1,387자)와 같습니다.
- 글리프는 24×24 I4(4비트 명암), 8×8 타일 3×3으로 288바이트씩입니다.
- 한글은 히라가나·가타카나·한자 슬롯 1,254개에 차례로 배정합니다. 번역에 쓰인 한글은 950자입니다.
- 배정 순서는 `text/hangul_order.txt`로 고정해, 메모리 카드에 저장된 한글 이름(기록·고스트)이 다시 빌드해도 깨지지 않게 했습니다.
- 영숫자·기호와 원래 글자표의 반각 문자는 그대로 둡니다.

## 문자열 교체

- REL 문자열은 원래 자리(칸 = 다음 문자열 직전까지, 4바이트 정렬)에 다시 써서 포인터를 바꾸지 않습니다. 칸을 넘으면 보고서에 `OVER`로 남깁니다.
- 번역 파일 `text/ko/<모듈>.txt`는 `오프셋<TAB>한국어` 형식입니다. `@`로 시작하는 줄은 같은 원문의 다른 사본(추적되지 않은 사본)에 따로 맞춘 짧은 번역입니다.
- 번역한 문자열이 같은 모듈 안 다른 위치에 그대로 또 있으면, 그 사본도 같이 바꿉니다(`dup_pass`).

## 인터뷰 대사

- `dlg/*_int.bin`은 0x138바이트 기록 16개입니다. 기록마다 질문 라벨(고정 칸)과 답변 문자열 영역을 가리키는 u16 포인터(+0x136)가 있습니다.
- 답변 영역은 통째로 다시 써서 길이 제한이 없고, 포인터를 갱신합니다. `\c1` 같은 색 제어 코드와 후리가나 `[…]`는 그대로 처리합니다.
- 번역은 `text/jp/dlg_seg.txt`·`dlg_label.txt`의 줄 번호로 연결합니다(`text/ko/` 같은 이름 파일).

## 스토리 자막

- `movie/story*.txt`는 `시작 프레임, 표시 길이, 글자 크기, 줄 번호, 문장*` 형식의 Shift-JIS 텍스트입니다(`*e.txt`는 영어판용). 문장만 바꾸고 후리가나 `[…]`는 지웁니다.

## 일시정지 메뉴 (gettext)

- `game/ja.gmo`는 GNU gettext MO 형식입니다. 번역문 37개를 항목 번호 순서대로 다시 써 넣고 오프셋 표를 갱신합니다.
- `game/game_msg_jp.txt`는 `키:값` 줄 형식이며, 값만 바꿉니다.

## 이름 입력

- 이름 입력 화면의 히라가나·가타카나 표를 한글 음절 두 세트(기본 95자, 이름용 92자)로 바꾸고, 탁음 변환 표는 비웠습니다(`kana.py`).

## 그림 글자 (TPL)

- `bmp/*.tpl.lz`는 AV LZ로 압축한 텍스처 묶음입니다. 머리에 16바이트 항목(형식, 오프셋, 폭, 높이, 밉맵 수, `0x1234`)이 텍스처 수만큼 있습니다.
- RGB5A3·I4·IA8 등 GameCube 형식을 `tpl.py`로 풀고 다시 인코딩합니다.
- 바꾼 텍스처: 머신 선택의 가속/최고속(`bmp_sel` #35), 레이더 차트(`bmp_conf` #0, `bmp_gar` #3), 코스 아웃 경고(`bmp_rac` #12), AX 코스 이름(`bmp_pas` #1), 선택머신·선택인물 링(`bmp_sel1w` #2, #3).
- 원래 글자는 OpenCV 인페인팅으로 지우고 그 위에 한글을 그립니다.

## 번역하지 않은 것

- 음성, 영문 로고·영문 메뉴 제목(MODE SELECT 등 원래 영어인 그림 글자), 코스·머신 영문 이름, 저작권 표기
- 디스크 배너(Shift-JIS 고정 칸)
