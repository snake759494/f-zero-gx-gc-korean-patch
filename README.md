# F-ZERO GX GC 한글패치

GameCube 일본판 **F-ZERO GX(エフゼロ ジーエックス, GFZJ01)**용 비공식 한국어 패치입니다. 다음 항목을 한국어로 바꿨습니다.

- **메뉴·화면 문자열 1,122개:** 모드 선택, 그랑프리·타임 어택·연습, 머신 선택·세팅, 커스터마이즈(차고·엠블럼 에디터·상점), 옵션, 파일럿 프로필, 도움말·확인 창
- **스토리 모드:** 챕터 제목·줄거리, 미션 설명, 컷신 자막 153줄
- **우승 인터뷰:** 파일럿별 질문 174개와 답변 1,546줄
- **레이스 중 메뉴:** 일시정지·리타이어·저장 확인 창 등 메시지 73개
- **이름 입력:** 가나 표를 한글 음절 표로 바꿔 한글 이름을 쓸 수 있습니다
- **화면 그림 글자:** 레이더 차트, 머신 선택의 가속/최고속, 선택머신·선택인물 링, 「코스 아웃!」 경고, AX 코스 이름
- **숨겨진 AX 모드:** 아케이드판 F-ZERO AX 모드(Dolphin 내장 치트 "F-Zero AX (Version 4)")의 안전 안내 화면, 모드 설명, 메모리 카드 안내, 가상 플레이어 이름·라이선스, 그림 글자 21장
- **게임 글꼴:** 번역에 쓰인 한글 951자를 나눔스퀘어네오로 새로 그렸습니다

현재 배포판은 **v1.1 (2026-11-21)**입니다.

## 게임 소개 및 대상 버전

『F-ZERO GX』는 닌텐도와 세가(어뮤즈먼트 비전)가 함께 만들어 2003년 7월 GameCube로 발매한 초고속 레이싱 게임입니다. 시속 1,000km가 넘는 속도로 30대의 머신이 겨루는 그랑프리와, 캡틴 팔콘이 주인공인 스토리 모드, 머신을 직접 조립하는 커스터마이즈가 들어 있습니다.

이 패치는 **일본판 GFZJ01 (Rev 0)**에만 적용됩니다. 파일 이름보다 아래 표의 크기와 해시가 맞는지가 중요합니다.

## 패치 적용 방법

### 1. RVZ·GCZ·CISO를 ISO로 바꾸기

xdelta는 **압축하지 않은 ISO**에만 적용됩니다. 원본이 RVZ 등 압축 형식이면 먼저 Dolphin에서 ISO로 바꿉니다.

1. Dolphin 게임 목록에서 게임을 우클릭하고 **파일 변환**을 고릅니다.
2. 형식을 **ISO**로 정하고 변환합니다. 이때 "쓰레기 데이터 제거"는 끄세요. 켜면 해시가 달라집니다.

명령줄에서는 다음과 같이 합니다.

```powershell
.\DolphinTool.exe convert -i '.\F-Zero GX (Japan).rvz' -o '.\F-Zero GX (Japan).iso' -f iso
```

### 2. 해시 확인

```powershell
Get-FileHash -Algorithm MD5 -LiteralPath '.\F-Zero GX (Japan).iso'
```

위 표와 다르면 적용을 중단하세요.

### 3. xdelta UI로 적용

1. 릴리즈에서 `F-Zero_GX_GC_KO_v1.1.xdelta`를 받습니다.
2. xdelta3 패치를 지원하는 도구에서 **Apply Patch** 기능을 엽니다.
3. **Patch**에는 xdelta 파일을, **Source File**에는 해시가 일치하는 원본 `.iso`를 선택합니다.
4. **Output File**에는 새 파일 이름을 지정합니다(예: `F-Zero GX (Korean).iso`).

xdelta는 호환성을 위해 압축·2차 압축·파일 경로 헤더 없이 만들었습니다. xdelta 자체는 [공식 프로젝트](https://github.com/jmacd/xdelta)를 참고하세요.

### 명령줄로 적용

```powershell
.\xdelta3.exe -d -s '.\F-Zero GX (Japan).iso' '.\F-Zero_GX_GC_KO_v1.1.xdelta' '.\F-Zero GX (Korean).iso'
```

결과 ISO는 Dolphin에서 그대로 실행하거나, 원하면 다시 RVZ로 변환해 보관해도 됩니다.

**세이브**
- 게임 ID는 원본과 같으므로 메모리 카드 세이브는 원본판과 함께 쓸 수 있습니다. 다만 원본판에서 일본어로 입력한 이름은 한글 글꼴 때문에 다른 글자로 보입니다.
- 원본판에서 만든 세이브 스테이트는 쓰지 마세요.

**와이드 화면**
- 게임 옵션 → 화면 모드에서 **와이드 TV**를 고르면 16:9로 표시됩니다. 별도의 와이드 패치는 필요 없습니다.

## 한글화 범위

- **메뉴·화면 문자열:** 공용 모듈과 화면별 모듈(타이틀, 선택, 스토리, 커스터마이즈, 옵션, 프로필, 인터뷰, 무비, 파일럿 포인트)의 문자열 1,122개.
  - 머신·파츠 설명, 상점 품목, 파일럿 프로필(나이·성별·경력 소개), 옵션 설명, 엠블럼 에디터 도움말 포함
- **스토리 모드:** 챕터 제목·줄거리, 미션 목표, 컷신 자막 153줄
- **우승 인터뷰:** 파일럿별 질문 174개, 답변 1,546줄, 인터뷰 화면 뉴스 자막
- **레이스 중 메뉴:** 일시정지·리타이어·리플레이·고스트 저장 확인 창, 입고 알림
- **이름 입력:** 가나 표 대신 한글 음절 표(기본 95자, 이름용 92자)
- **그림 글자:**
  - 머신 성능 레이더 차트(바디·코너링·가속력·최고속), 차고 레이더 차트
  - 머신 선택의 가속/최고속 표시, 선택머신·선택인물 링
  - 「코스 아웃!」 경고, AX 코스 이름 6개
- **AX 모드:** 「플레이하기 전에」 안전 안내 판, 액셀 온·카드 인·라이선스 카드·이어받기·사용 안 함·만들기 등 버튼 글자, 「메모리 카드도 접수 중!」, 「대전 상대 모집 중」, 「인 대전 가능」, 고스트 종류 표시, 레이더 차트, 모드 설명·메모리 카드 안내 문장, 가상 플레이어 이름·라이선스
  - AX 모드 라이선스 카드 그림 뒷면의 작은 약관 글씨는 그대로 두었습니다.
- **글꼴:**
  - 게임 글꼴(메뉴·대사)은 번역에 쓰인 한글 951자를 나눔스퀘어네오로 그렸습니다.
  - 그림 글자는 나눔스퀘어네오와 서울한강체(AX 모드 붓글씨풍 문구), 아주 작은 글씨는 갈무리를 썼습니다.
- **원문 유지:** 음성(일본어·영어 실황), 원래 영어로 된 로고·메뉴 제목(MODE SELECT 등), 코스·머신의 영문 이름, 저작권 표기, 디스크 배너.

## 알려진 한계

**표기**
- 고유명사는 북미판과 국내 통용 표기를 참고해 적었습니다(예: 캡틴 팔콘, 블랙 섀도, 사무라이 고로).
- 원래 칸 크기에 맞추느라 일부 문장을 줄여 적었습니다.

**확인 범위**
- Dolphin에서 직접 조작해 확인한 화면: 타이틀, 모드 선택, 이름 입력, 스토리 컷신·미션, 머신 선택·세팅, 레이스 일시정지·리타이어, 타임 어택, 연습, 엠블럼 에디터, 상점, 차고, 옵션, 파일럿 프로필.
- AX 모드는 Dolphin 내장 치트로 켜서 안내 화면, 모드·코스·머신 선택, 머신 세팅, 레이스, 일시정지를 확인했습니다.
- 레이스 결과·시상, 우승 인터뷰, VS 배틀은 데이터와 칸 넘침이 없는 것(0건)만 확인했습니다.
- 실기 GameCube에서의 동작은 확인하지 못했습니다.

문제가 있으면 이슈로 알려 주세요.
